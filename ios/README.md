# Radio Românii din Italia — iOS

Questo progetto contiene l’app iOS nativa associata al Bundle ID:
`org.radioromaniidinitalia.radio`.

L’app apre il sito ufficiale della radio in una WebView con supporto alla riproduzione audio in background.

Per la distribuzione:
1. Aprire `ios/RadioRomanii.xcodeproj` in Xcode.
2. Selezionare il team Apple Developer con firma automatica.
3. Eseguire Archive e caricare il build in App Store Connect.
