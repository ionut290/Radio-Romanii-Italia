# Fotografie originali del calendario filosofico RDI

Questa cartella contiene le immagini originali pubblicabili dal calendario filosofico.

Per il 16 novembre 2026, il file atteso è `2026-11-16.jpg` (JPEG, almeno 10 KB).
La frase abbinata è già approvata in `data/calendario-filosofico-2026.json`:

> Quando una mano si tende, la distanza fra due mondi diminuisce.

Quando il JPEG viene aggiunto sul branch `main`, il workflow esistente `RDI - Pubblica foto del calendario` verifica la presenza del file e aggiorna il puntatore di oggi. Non cambiare il puntatore manualmente prima di aver caricato e verificato l'immagine. Le foto create con IA vanno indicate come tali. Non sono fotografie documentarie di eventi reali.
